# 目标检测 + 语义分割标注工具 (v1.1)

一个基于 PyQt5 的桌面标注工具，支持在同一张图片上同时标注目标检测框和分割区域。

## 功能

- **目标框标注**：拖拽绘制矩形，可移动、缩放、删除，导出 Pascal VOC 格式的 `.xml` 文件；不同类别用不同颜色显示，颜色对应关系见右侧“类别配置”的图例。
- **分割标注**：绘制多边形区域，最多 3 个类别，分别写入 PNG 的 **R / G / B** 三个通道；同时把顶点与类别写入同名 XML，切图返回后仍可继续编辑。
- **类别配置写入 `config.json`**：可直接编辑配置文件（改完约 1 秒自动同步到软件），软件内改类别也会写回文件。
- 图片上标注的分割区域直接显示配置中的类别名，不再是“类别1/2/3”。
- 支持打开单张图片或整个文件夹（**递归扫描所有子目录**），图片列表显示相对路径，可区分重名文件。
- 打开图片时自动读取同目录下已有 XML 中的目标框和分割多边形（旧版只有掩码图也能恢复），可直接修改。
- **类别可随时修改**：右侧标注面板同一个“选中类别”下拉框，选中框时改检测类别，选中分割区域时改分割类别，都只能从配置好的类别中选择。
- **实时自动保存**：每次新增/移动/删除/改类别后立即写入文件；可在“设置”菜单关闭。
- **↑ / ↓ 切换图片**：画布获得焦点时按上下箭头切换上一张/下一张。
- **分割顶点可编辑**：绘制中右键删除指向的顶点；完成后选中多边形可拖动任意顶点调整轮廓。
- **分割图输出可控**：可开关“自动生成 PNG”，并配置文件名后缀（原名 / `_mask` / 自定义）。
- **一键导出全部 Mask**：点击工具栏“导出全部Mask”，批量为所有有分割标注的图片生成 PNG，没有分割标注的图片自动跳过。
- 滚轮缩放、中键拖拽平移、适应窗口；标注列表可选中/删除/清空。

## 配置文件

`config.json` 位于程序目录，修改后软件会自动同步（约 1 秒轮询），也可在“设置 → 重新加载配置文件”手动触发。

```json
{
  "box_classes": ["excavator", "people", "person", "car", "bicycle", "object"],
  "seg_classes": ["类别R", "类别G", "类别B"],
  "output_dir": null,
  "auto_generate_mask": true,
  "mask_suffix": "_mask"
}
```

- `box_classes`：检测框类别，写入 XML 的 `<name>`。
- `seg_classes`：分割类别，最多 3 个，依次对应 R / G / B 通道，同时作为图上显示的名称。
- `output_dir`：标注输出目录，`null` 表示与图片同目录。
- `auto_generate_mask`：标注变动时是否自动生成分割 PNG；关闭后只有手动“导出分割 PNG”才会生成。
- `mask_suffix`：掩码文件名后缀。`"_mask"` 得到 `img_001_mask.png`，`""` 得到 `img_001.png`（若与源图片同名会自动退回 `_mask`），也可填 `"_seg"` 等自定义值。

启动软件**不会改写** `config.json`；只有在软件里点击“应用检测类别 / 应用分割类别”或更改输出目录时才会写回。若 JSON 格式有误，软件会保留当前类别并在状态栏提示，不会用默认类别覆盖你的文件。

## 安装

```bash
pip install -r requirements.txt
```

## 运行

```bash
python main.py
```

## 操作说明

### 检测模式

1. 工具栏选择“检测框”，并选定检测类别。
2. 在图片上拖拽鼠标绘制矩形框。
3. 点击框可选中，拖动框可整体移动，拖动四角控制点可缩放。
4. 按 `Del` 或点击“删除选中”移除。
5. 选中框后，在右侧“选中类别”下拉框中选择新类别，修改会立即保存。

标注变动后自动在与图片相同的目录（或指定输出目录）生成/更新 `<图片名>.xml`：

```xml
<annotation>
  <filename>img_001.jpg</filename>
  <size>
    <width>640</width>
    <height>480</height>
    <depth>3</depth>
  </size>
  <object>
    <name>person</name>
    <bndbox>
      <xmin>36</xmin>
      <ymin>58</ymin>
      <xmax>182</xmax>
      <ymax>301</ymax>
    </bndbox>
  </object>
  <segmentation>
    <region class_id="0" label="类别R">
      <point x="10" y="20" />
      <point x="80" y="20" />
      <point x="80" y="60" />
      <point x="10" y="60" />
    </region>
  </segmentation>
</annotation>
```

### 分割模式

1. 工具栏选择“分割区域”，并选定类别（1/2/3 对应 R/G/B 通道）。
2. 依次点击添加多边形顶点。
3. 绘制过程中**右键点击顶点可删除该点**；双击、点击起点或按 `Enter` 完成，`Esc` 取消。
4. 完成后点击多边形内部可选中并整体移动；拖动白色控制点可调整单个顶点位置（至少保留 3 个点）。
5. 图上标注文字取自 `config.json` 中的 `seg_classes`。

标注变动后自动生成/更新 `<图片名>_mask.png`（尺寸与原图一致），同时把多边形顶点写入同名 XML 的 `<segmentation>` 节点，因此切换图片后返回仍可继续调整：

| 类别 | 通道 | 像素值 |
| --- | --- | --- |
| 类别 1 | R | `(255, 0, 0)` |
| 类别 2 | G | `(0, 255, 0)` |
| 类别 3 | B | `(0, 0, 255)` |

背景为 `(0, 0, 0)`。不同类别在多边形重叠时按绘制顺序覆盖。

点击工具栏“导出全部Mask”可一次处理当前打开的全部图片：从各图片的 XML（或旧版掩码）读取分割标注，只为有分割标注的图片生成 PNG，没有分割标注的图片不会生成文件。导出使用配置中的输出目录和文件名后缀，不受“自动生成 PNG”开关影响。

## 快捷键

| 快捷键 | 功能 |
| --- | --- |
| `Ctrl+O` | 打开图片 |
| `Ctrl+Shift+O` | 打开文件夹 |
| `Ctrl+S` | 手动保存标注（平时自动保存） |
| `Del` | 删除选中标注 |
| `F` | 适应窗口 |
| `↑` / `↓` | 上一张 / 下一张（画布焦点） |
| `Ctrl+Left` / `Ctrl+Right` | 上一张 / 下一张 |
| `Enter` | 完成当前多边形 |
| `Esc` | 取消当前绘制 |
